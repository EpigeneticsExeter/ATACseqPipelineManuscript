# PIPPA

This is the repository for scripts used to generate figures in the paper: *PIPPA: Pipeline for Integrative Peak calling in Population-scale ATAC-seq. An integrative pipeline for curation of large-scale ATAC-seq data: 
from raw reads to high confidence peak sets* paper. 

Full pipeline can be accessed from: [BrainFANS](https://github.com/ejh243/BrainFANS/tree/master/sequencing/ATACSeq)
